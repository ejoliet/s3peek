# s3peek — Architecture & API Reference

## Architecture

```
┌──────────────────────────────────────────────────────────┐
│                        s3peek CLI                        │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────────┐  │
│  │  TUI browser │  │  Quicklook   │  │  Presign cmd   │  │
│  │  (Textual)   │  │  engine      │  │  (boto3)       │  │
│  └──────┬───────┘  └──────┬───────┘  └───────┬────────┘  │
│         └─────────────────┴──────────────────┘           │
│                      S3 abstraction layer                 │
│                  (boto3 + range-GET)                      │
└──────────────────────────────────────────────────────────┘
         │                                    │
    AWS S3 API                         Clipboard (pyperclip)
```

### Key design decisions

- **Range-GET for headers** — FITS/Parquet headers read via HTTP `Range` requests (first N bytes, configurable via `max_range_get_bytes`). No full download.
- **ASDF/FITS dual-mode read** — fast path: raw byte parse of first N KB (no heavy lib). Deep-inspect path (`--deep`): `SeekableS3Stream` issues Range-GETs on demand as astropy/asdf seek — full multi-HDU / full ASDF tree, no full download.
- **SeekableS3Stream** (`streams.py`) — file-like object backed by S3 Range-GETs with 256 KB chunk cache. Passed directly to `astropy.io.fits.open()` / `asdf.open()` so libraries only fetch what they actually read.
- **No local state** — no DB, no cache. All navigation state in-memory per session.
- **Synchronous boto3 inside Textual** — Textual `@work(thread=True)` handles offloading. Do not refactor to `aioboto3` (mixing async stacks has broken adjacent tools).

## CLI Reference

```
s3peek [OPTIONS] COMMAND [ARGS]

Commands:
  browse   Interactive TUI browser for a bucket or prefix
  config   Show resolved config file path and current values
  du       Summarize storage usage under an S3 prefix
  firefly  Send an S3 object to a Firefly visualization server
  ls       List objects under an S3 prefix
  peek     Print header/schema of a single S3 object to stdout
  share    Generate a pre-signed URL; copy to clipboard
  version  Print version and exit
```

### peek options

```
s3peek peek S3_URI [OPTIONS]

Options:
  --output TEXT           text or json [default: text]
  --max-hdus INTEGER      Max HDUs to show [default: 1]
  --deep                  Full header via astropy/asdf (streams via Range-GETs)
  --max-range-bytes INT   Override fast-path Range-GET limit

Exit codes: 0=success  1=S3 error  2=format unsupported  3=parse error
```

### share options

```
s3peek share S3_URI [OPTIONS]

Options:
  --expiry TEXT      Expiry: 1h, 30m, 7d [default: 1h]
  --qr               Print QR code (requires s3peek[qr])
```

### firefly options

```
s3peek firefly S3_URI [OPTIONS]

Options:
  --server TEXT    Firefly server URL (or FIREFLY_URL env)
  --channel TEXT   Browser tab channel (or FIREFLY_CHANNEL env)
  --open-browser   Open Firefly in a browser tab
  --title TEXT     Display title
```

## Quicklook Output Contract

Each format reader returns `HeaderResult`:

```python
@dataclass
class HeaderResult:
    format: str                        # "fits" | "asdf" | "parquet" | "json"
    s3_uri: str
    size_bytes: int | None
    headers: list[dict[str, Any]]      # one dict per HDU (FITS) or one (others)
    truncated: bool = False            # True if range-GET hit max_bytes
    error: str | None = None
```

FITS `headers[n]`:
```python
{"hdu_index": 0, "hdu_type": "PrimaryHDU", "naxis": 2, "shape": [2048, 2048],
 "cards": {"SIMPLE": True, "BITPIX": -32, ...}}
```

ASDF `headers[0]`:
```python
{"asdf_version": "1.6.0", "tree": {...}}   # arrays summarized, not expanded
```

Parquet `headers[0]`:
```python
{"num_rows": 1048576, "num_row_groups": 4,
 "schema": [{"name": "ra", "type": "DOUBLE", "nullable": False}, ...],
 "metadata": {...}}
```

JSON `headers[0]`:
```python
{"type": "object", "keys": ["ra", "dec", "mag"], "length": 3}
```

## Data Model

No persistent storage. Runtime state:

```python
@dataclass
class SessionState:
    bucket: str
    prefix: str = ""
    history: list[str] = field(default_factory=list)
    selected_key: str | None = None
```

Config (loaded once at startup):

```python
class Config(BaseModel):
    aws_profile: str | None = None
    aws_region: str | None = None
    default_bucket: str | None = None
    presign_expiry_seconds: int = 3600
    max_range_get_bytes: int = 65536
    theme: str = "dark"
    firefly_url: str | None = None
    firefly_channel: str | None = None
```

## Error Classes

| Exception | When | Exit code | User message |
|-----------|------|-----------|--------------|
| `S3AccessError` | 403 / no credentials | 1 | `"AWS credentials missing or insufficient permissions"` |
| `S3KeyNotFoundError` | 404 | 1 | `"Object not found: s3://..."` |
| `FormatNotSupportedError` | Unknown extension | 2 | `"Format not supported. Supported: fits, asdf, parquet, json"` |
| `QuicklookParseError` | Unreadable header bytes | 3 | `"Could not parse header — file may be truncated or corrupt"` |
| `PresignExpirySyntaxError` | Invalid expiry string | 1 | `"Invalid expiry format. Use: 1d, 6h, 30m"` |
| `PresignExpiryTooLongError` | Expiry > 7 days | 1 | `"Maximum expiry is 7 days (604800 seconds)"` |

All errors → `stderr`. `stdout` reserved for data output only.

## Non-Goals (v1)

- No upload, delete, or copy — read-only
- No recursive download (`aws s3 sync` for that)
- No full file render — headers/schema only
- No bucket creation or policy management
- No Windows support
- No HiPS / MOC / VOTable quicklook (v2 candidate)
- No GCS, Azure, or other cloud providers
